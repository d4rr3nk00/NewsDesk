# 취재 데스크 Alpha

Windows 설치 파일과 Android APK는 이 비공개 저장소의 Releases에서 받으세요.

- Windows 10/11 64비트: 설치 EXE 실행 후 바탕화면 아이콘으로 시작합니다. Python을 별도로 설치할 필요가 없습니다.
- Android 8 이상: APK를 설치합니다. 취재 자료를 열려면 별도 HTTPS 공유 서버가 필요합니다.
- 현재 공유 서버는 배포되지 않았습니다. Windows의 PC 저장 기능부터 사용할 수 있습니다.
- 검증: Windows 설치 및 내장 서버를 Wine에서 검사했고, 앱 화면 기능은 Linux Electron에서 검사했습니다. Android 15 가상 기기에 설치·실행을 확인했습니다. 실제 Windows PC와 실제 휴대폰 전체 기능 검증은 남아 있습니다.
- 알파 설치 파일은 상용 코드 서명을 받지 않았습니다.

이 문서는 설치 파일 전달을 위한 안내입니다.
