취재 데스크 Alpha 0.2

Windows 10/11 64비트
1. NewsDesk-0.2.0-alpha-Setup.exe 실행 → 설치
2. 바탕화면의 취재 데스크 Alpha 아이콘 실행
3. 취재 데스크 시작 선택
Python을 따로 설치할 필요가 없습니다.

Android 8 이상
NewsDesk-0.2.0-alpha.apk를 휴대폰에 내려받아 설치합니다.
공유 서버가 준비되면 HTTPS 주소와 서버 계정으로 연결합니다.

현재 공유 서버는 없습니다.
Windows PC 저장 기능은 바로 사용할 수 있습니다.
Android에서 PC의 자료를 보려면 별도 공유 서버가 필요합니다.
PC 저장과 서버 저장은 별개이며 자동으로 자료를 옮기지 않습니다.
이전은 취재별 ZIP 백업 → 백업 복원을 사용하세요.
다른 기기의 변경 내용은 새로고침으로 불러옵니다.

PC 자료 위치: %APPDATA%/NewsDesk/data
앱 메뉴의 PC 자료 폴더 열기로 확인할 수 있습니다.
앱 제거 시 자료는 삭제하지 않습니다.

이 알파는 정식 배포 서명을 받지 않은 시험 버전입니다.
검증 범위와 남은 제한은 검증 결과.md 및 README.md를 참조하세요.
