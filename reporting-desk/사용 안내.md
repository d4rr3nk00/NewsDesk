# 취재 데스크 사용 안내

개인 컴퓨터에서 실행하는 취재 정리 웹앱입니다. 서버는 `127.0.0.1`에서만 실행되며, 기록과 등록한 자료는 이 폴더의 `data` 폴더에 저장합니다. **AI 분석을 직접 요청하고 전송 범위를 확인하면**, 선택한 정보가 인터넷을 통해 OpenAI API로 전송됩니다. 그 밖의 일반 작업에는 인터넷이 필요하지 않습니다.

## 실행

1. ZIP으로 받았다면 먼저 압축을 풉니다. 압축 파일 안에서 실행하지 마세요.
2. Windows에서 `run.bat`을 두 번 클릭합니다. Python 3.10 이상이 필요하며, 별도 패키지 설치는 필요 없습니다.
3. 브라우저가 자동으로 열립니다. 열리지 않으면 실행 창에 표시된 `http://127.0.0.1:포트번호/` 주소를 엽니다.
4. 작업을 마치면 실행 창을 닫아 프로그램을 종료합니다. 같은 프로그램을 다음에 열면 저장된 자료를 그대로 볼 수 있습니다.

**저장 위치:** `app.py` 옆의 `data` 폴더. 이 폴더를 지우거나 옮기면 취재 자료에도 영향을 줍니다. 다른 컴퓨터로 옮길 때는 프로그램과 `data` 폴더를 함께 옮기거나 아래의 취재 건별 백업을 이용하세요.

### 이전 버전에서 업데이트

- 같은 폴더의 프로그램 파일을 업데이트했다면 실행 중인 취재 데스크를 닫고 `run.bat`을 다시 실행하세요. 기존 `data`는 그대로 둡니다.
- ZIP을 다른 위치에 새로 풀었다면 이전 프로그램의 `data` 폴더를 먼저 안전한 위치에 백업한 다음, 새 `reporting-desk` 폴더 안으로 복사하세요. 이전 폴더와 원본 `data`도 보관해 두세요. AI 연결 ZIP에는 `data`가 포함되지 않습니다.

## 처음 시작하기

1. **새 취재**를 눌러 제목이나 메모 한 줄을 입력합니다. 출입처, 마감과 보도 제한은 나중에 채워도 됩니다.
2. 취재 건의 **자료 등록**에서 파일, 링크 또는 메모를 등록합니다. 파일당 최대 50MB입니다. 파일 원본은 `data/files`에 저장됩니다.
3. **주장 추가**로 쓰려는 사실과 확인 상태, 허용 표현, 비교 조건, 계산 및 다음 질문을 기록합니다. **근거 연결**에서 자료 버전과 쪽수·표·셀·타임코드를 직접 적습니다.
4. 원고에서 제목·부제·문단을 작성하고 **연결 주장**을 선택합니다. **원고 저장**을 누르면 저장 이력이 남습니다. 여러 판을 추가하고 이전 저장본을 복원할 수 있습니다.
5. **내부 검토본**은 엠바고와 연결 근거를 포함합니다. **외부용 출력**은 공개 승인한 제목·부제·문단만 포함합니다. 출력 전 보도 가능 시점과 공개 범위를 확인해야 합니다.

## OpenAI 연결과 AI 분석

1. 인터넷에 연결한 뒤 앱 상단의 **AI 연결**에서 본인의 OpenAI API 키를 입력합니다. 키는 채팅에 보내지 말고 앱에 직접 입력하세요. 앱은 키를 프로그램 메모리에만 두며, 앱을 종료하면 다시 입력해야 합니다. 키 저장만으로 API 요청을 보내지는 않습니다.
2. 취재 건의 **AI 분석 보조 → 분석 요청**에서 `자료 분석` 또는 `주장 검토`를 선택합니다. 모델 ID는 직접 바꿀 수 있습니다. OpenAI API 키와 해당 모델의 사용 권한이 필요합니다.
3. 보낼 자료 버전과 주장을 직접 선택합니다. 최초에는 아무 자료도 선택되지 않습니다. 주장에 연결된 자료는 자동으로 포함되지 않으므로 대조할 자료도 따로 선택하세요. 파일은 원본 전체, 메모는 전문이 전송됩니다. 선택한 주장은 주장 문장, 종류, 상태, 허용 표현, 비교 조건과 산식을 포함합니다. 연락처와 답변 담당자 등 다른 항목은 자동으로 포함하지 않습니다.
4. **전송 내용 미리보기**에서 전송될 질문·메모·주장, 파일명과 파일 전체 전송 여부를 확인합니다. 취재원 보호 자료, 엠바고, 개인정보를 포함해도 되는지 살펴본 뒤 **확인하고 분석 요청**을 누릅니다. 확인 전에는 OpenAI로 보내지 않습니다. 미리보기에서 확인한 내용은 10분간 유효합니다.
5. 결과는 해당 취재 건에 로컬 저장되며 나중에 다시 볼 수 있습니다. AI는 확인 상태나 원고를 자동으로 바꾸지 않습니다. 자료·인용·수치·쪽수와 독립 출처는 기자가 직접 확인하고 판단해야 합니다.

**공개 웹 검색 허용**은 기본적으로 꺼져 있습니다. 켜면 선택한 요청 내용이 웹 검색 질의에 반영될 수 있고, 검색 결과에 표시된 출처 링크를 확인할 수 있습니다. 웹 검색을 끈 경우 링크 자료는 주소와 작성한 메모만 보내며 링크 본문은 자동으로 가져오지 않습니다.

지원 파일은 PDF, TXT, Markdown, DOC/DOCX, PPT/PPTX, XLS/XLSX, CSV/TSV 등입니다. AI로 보내는 파일은 하나당 10MB, 한 번에 합계 20MB까지입니다. HWP/HWPX는 PDF로 변환해 새 자료로 등록해 주세요. PDF 페이지 이미지 처리나 표 파일 처리는 비용이 커질 수 있으며, 대용량 표의 완전한 통계 집계나 OCR 정확도를 보장하지 않습니다.

ChatGPT 구독과 API 사용은 별도의 결제 체계이며, API 요청에는 모델·토큰·검색 도구 사용량에 따른 비용이 발생할 수 있습니다. 연결 오류나 시간 초과가 발생한 요청도 이미 처리되어 비용이 발생했을 수 있으므로 재시도 전에 API 사용 내역을 확인하세요. [OpenAI 모델 안내](https://developers.openai.com/api/docs/models)

앱은 OpenAI Responses API에 `store=false`를 요청하지만, 이 설정이 모든 보관을 없앤다는 뜻은 아닙니다. OpenAI의 안전·운영 목적 로그와 계정별 데이터 정책이 적용될 수 있습니다. 취재원 보호가 필요한 자료는 이를 고려해 전송 여부를 결정하세요. [OpenAI API 데이터 정책](https://developers.openai.com/api/docs/guides/your-data)

엠바고가 시각 기준이면 해당 한국시간 전에 외부용 출력이 차단됩니다. 사건 기준이면 취재 정보에서 사건 발생 및 해제를 직접 확인해야 합니다. 자료에 새 버전을 등록하면 기존 버전은 남고 연결된 주장은 재확인 대상으로 표시됩니다. 재확인 대상, 보류·상충·확인 대기 또는 내부 검토용 주장에 연결된 공개 문장은 외부 출력이 차단됩니다. `추정임을 표시`로 정한 주장의 연결 문장에는 `추정` 또는 `추산`이 들어 있어야 합니다.

문장과 주장 연결, 확인 상태, 공개 승인, 인용의 정확성은 기자가 직접 판단해야 합니다. 프로그램이 모든 문장을 자동으로 분석하거나 취재원 정보를 자동으로 가려 주지는 않습니다. 자료 공개 범위 표시는 참고 정보이며, 공개 문장에 민감한 내용을 직접 넣지 않았는지 출력 전 검토해야 합니다. 자료의 공개 범위를 바꾸면 연결된 주장에도 재확인 표시가 생깁니다.

같은 원고를 여러 창에서 열어 두었다가 다른 창에서 먼저 저장하면, 나중에 저장하는 창에는 충돌 안내가 뜹니다. 저장 전 수정 내용을 별도로 복사한 뒤 새로고침해 최신 저장본과 비교하세요. 자동 병합 기능은 제공하지 않습니다.

## 백업과 복원

취재 건 안의 **이 취재 건 백업**으로 자료 파일, 메모, 주장, 원고, AI 분석 결과와 이력이 포함된 ZIP을 저장할 수 있습니다. 오늘 화면의 **백업 복원**을 누르면 별도 취재 건으로 복원합니다. 이전 오프라인 버전에서 만든 백업도 복원할 수 있습니다. 복원할 ZIP은 압축된 크기 50MB 이하, 내부 파일 합계 200MB 이하여야 합니다. API 키는 백업에 포함되지 않습니다.

백업은 **암호화되지 않습니다.** 취재원 정보가 포함될 수 있으니 접근이 제한된 곳에 보관하세요. 브라우저의 일반 다운로드 폴더에 저장될 수 있으므로 저장 위치도 확인하세요. 자료를 보호하려면 컴퓨터의 디스크 암호화와 계정 잠금 기능을 사용하세요.

## 이번 버전에서 직접 해야 하는 일

- 로컬 프로그램은 PDF·한글 문서·녹취에서 텍스트나 표를 자동 추출하지 않습니다. 지원되는 파일을 선택해 OpenAI에 분석 요청할 수 있으나, 결과의 쪽수·시간·셀과 인용은 원문에서 직접 확인해야 합니다. PDF는 브라우저에서 열 수 있고, 그 밖의 파일은 내려받아 해당 프로그램에서 확인합니다.
- AI가 제안하는 검토는 독립적인 사실 확인을 보장하지 않습니다. 원고 자동 생성, 자료 변경점 자동 추출, CSV의 결정론적 집계와 그래픽 생성은 제공하지 않습니다. **기본 구성 넣기**는 빈 작성 틀만 넣습니다.
- 자료의 새 버전이 올라오면 관련 주장을 재확인 대상으로 표시하지만, 어느 문구와 수치가 달라졌는지는 직접 비교해야 합니다.
- 원고지 매수는 본문 공백 포함 글자 수를 200으로 나눈 단순 환산값입니다. 지면별 편집 기준에 맞춰 다시 확인하세요.
- 자료는 하나의 취재 건에 속하며, 다른 취재 건에서 자동으로 공유되지는 않습니다.

## 문제가 생겼을 때

- `Python ... is required`가 표시되면 Python 3.10 이상을 설치한 뒤 다시 실행합니다.
- 창이 바로 닫히거나 화면이 열리지 않으면 실행 창의 오류 메시지를 확인하세요. 이미 다른 프로그램이 기본 포트를 사용하면 다음 포트로 자동 이동합니다.
- 기록을 보호하려면 `data` 폴더를 주기적으로 별도 저장 장치에 백업하세요. 앱 업데이트 전에 반드시 백업을 권장합니다.
